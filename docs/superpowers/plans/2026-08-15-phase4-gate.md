# Phase 4-e 版本对比与回归门禁 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理员选择两个已完成的评测运行（baseline/candidate），获得逐指标对比报告与回归门禁判定（PASS/FAIL/INCOMPLETE）。纯计算、不落库。

**Architecture:** 在 evaluation 模块新增 `EvaluationComparisonService` + REST 端点 `/api/evaluation/comparisons`。门禁规则硬编码（完整性 + 相对退化 10%）。前端 RunPanel 增加对比区。

**Tech Stack:** Java 21、Spring Boot 4、Spring Modulith、Jackson 3 (`tools.jackson`)、React 19 + TypeScript + Vite + Vitest。

## Global Constraints

- 门禁阈值硬编码：相对退化 `0.10`；四类关键指标 `avgMrr`/`avgNdcgAt10`/`citationHitRate`/`refusalMatchRate`。
- 完整性：任一 run 非 `COMPLETED` 或 `completedCount != caseCount` → `INCOMPLETE`。
- `latency` 只报告不判定。
- 纯计算、不落库、无新迁移。
- evaluation 模块边界不变（`{shared, iam::api, retrieval::api, generation::api, configuration::api}`）。
- TDD，每 Task 独立提交。

- [ ] **Step 2: 实现值对象 + 服务**

`EvaluationComparisonService`：

```java
private static final double MAX_REGRESSION = 0.10;

public ComparisonResult compare(UUID baselineRunId, UUID candidateRunId) {
    EvaluationRun baseline = requireRun(baselineRunId);
    EvaluationRun candidate = requireRun(candidateRunId);
    RunMetrics b = deserialize(baseline.getMetricsJson());
    RunMetrics c = deserialize(candidate.getMetricsJson());

    List<MetricComparison> metrics = List.of(
        metric("Recall@1", b.avgRecallAt1(), c.avgRecallAt1()),
        metric("Recall@3", b.avgRecallAt3(), c.avgRecallAt3()),
        metric("Recall@5", b.avgRecallAt5(), c.avgRecallAt5()),
        metric("MRR", b.avgMrr(), c.avgMrr()),
        metric("NDCG@10", b.avgNdcgAt10(), c.avgNdcgAt10()),
        metric("Citation hit", b.citationHitRate(), c.citationHitRate()),
        metric("Refusal match", b.refusalMatchRate(), c.refusalMatchRate()),
        metric("Avg latency (ms)", b.avgLatencyMs(), c.avgLatencyMs()));

    if (incomplete(b) || incomplete(c)) {
        return new ComparisonResult(baselineRunId, candidateRunId, b, c, metrics,
                GateVerdict.INCOMPLETE, List.of());
    }

    List<GateCheck> failed = new ArrayList<>();
    checkRegression(failed, "MRR", b.avgMrr(), c.avgMrr());
    checkRegression(failed, "NDCG@10", b.avgNdcgAt10(), c.avgNdcgAt10());
    checkRegression(failed, "Citation hit", b.citationHitRate(), c.citationHitRate());
    checkRegression(failed, "Refusal match", b.refusalMatchRate(), c.refusalMatchRate());

    GateVerdict verdict = failed.isEmpty() ? GateVerdict.PASS : GateVerdict.FAIL;
    return new ComparisonResult(baselineRunId, candidateRunId, b, c, metrics, verdict, failed);
}
```

辅助：`incomplete(RunMetrics)` = `completedCount != caseCount`；`checkRegression` = `candidate < baseline * (1 - MAX_REGRESSION)` 则加 GateCheck（maxAllowed = `baseline * 0.90`）。
